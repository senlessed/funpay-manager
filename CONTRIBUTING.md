# Разработка

Python 3.12 x64, установка и команды проверки описаны в README. Изменения делаются
по этапам PLAN.md. Не добавляйте заглушки под видом работающих функций. Каждое
изменение данных — отдельная атомарная миграция и тест рестарта/ошибки.

Не используйте реальные токены в тестах. FunPay network contract tests выполняются
отдельно; реальные сообщения/поднятия требуют разрешения владельца аккаунта.
Не логируйте сетевые исключения целиком. GUI не обращается в сеть и не меняется
из backend-потока. Прежде чем добавить зависимость, проверяйте API, лицензию,
транзитивные пакеты и необходимость; обновляйте lock и документацию проверок.
