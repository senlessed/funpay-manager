# Безопасность

Не публикуйте токены, cookies, golden_key, SQLite, резервные копии или полные
HTTP-логи. Токен Telegram вводится только в локальном мастере настройки.
Сессионный ключ FunPay вводится в отдельном локальном диалоге. Доступны только
чтение профиля/чатов/истории. Отправка текстов разрешается отдельно пользователем
в Windows, по умолчанию выключена, проходит через сохраняемую очередь. При unknown
автоматического повтора нет. В автоматических проверках используются только mocks,
настоящих сообщений покупателям автоматические тесты не отправляют.
Автоподнятие обычных лотов требует отдельного включения в Windows и выбора категорий.
Перед POST повторно проверяются аккаунт, принадлежность выбранных разделов и
включённый режим. Попытка фиксируется до POST; неизвестный результат после сбоя
не повторяется автоматически. Restore выключает автоподнятие и чтение заказов.
Изменение цен, возвраты и финансовые операции не реализованы.
Никому не передавайте сессионные ключи для диагностики.

Перед публичным выпуском требуется настроить приватный канал сообщения об
уязвимостях (например, GitHub private vulnerability reporting). Наличие такого
канала пока не подтверждено. Не раскрывайте действующие секреты в публичном Issue.

CredentialStore принудительно использует Windows backend keyring. SQLite и backup
не зашифрованы: безопасность зависит от доступа к Windows-профилю. Проверки
авторизации Telegram выполняются до команд, кнопок и постановки текстов в очередь.
Личные уведомления отправляются только сохранённому owner ID после проверки bot ID.
URL preview и HTML parsing отключены. При неизвестной доставке повтора нет;
restore выключает автоматизации и повторно снимает тихую начальную точку истории.

Topics привязываются одноразовым кодом только сохранённым владельцем. Проверяются
закрытая forum-супергруппа без публичных username, геолокации и связанного канала,
права владельца и бота. Проверки повторяются перед созданием темы, зеркалом и
отправкой ответа. Изменение настроек Telegram между проверкой и запросом не может
быть исключено атомарно. Все участники группы могут читать все переписки;
не добавляйте посторонних. Темы не разграничивают доступ участников.
Отправлять текст может только владелец в известной теме текущей привязки после
локального opt-in; боты, анонимные отправители и пересылки отбрасываются.
Группу следует использовать только для переписки: обычный текст владельца в теме
при включённой отправке идёт покупателю. Старые очереди не получают права новой
привязки. При неопределённом создании/доставке автоматического повтора нет.
