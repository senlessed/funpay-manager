# Безопасность

Не публикуйте токены, cookies, golden_key, SQLite, резервные копии или полные
HTTP-логи. Токен Telegram вводится только в локальном мастере настройки.
Сессионный ключ FunPay вводится в отдельном локальном диалоге. Доступны только
чтение профиля/чатов/истории. Отправка текстов разрешается отдельно пользователем
в Windows, по умолчанию выключена, проходит через сохраняемую очередь. При unknown
автоматического повтора нет. В автоматических проверках используются только mocks,
настоящих сообщений покупателям не отправляли. Операций с лотами пока нет.
Никому не передавайте сессионные ключи для диагностики.

Перед публичным выпуском требуется настроить приватный канал сообщения об
уязвимостях (например, GitHub private vulnerability reporting). Наличие такого
канала пока не подтверждено. Не раскрывайте действующие секреты в публичном Issue.

CredentialStore принудительно использует Windows backend keyring. SQLite и backup
не зашифрованы: безопасность зависит от доступа к Windows-профилю. Проверки
авторизации Telegram выполняются до команд, кнопок и постановки текстов в очередь.
Личные уведомления отправляются только сохранённому owner ID после проверки bot ID.
URL preview и HTML parsing отключены. При неизвестной доставке повтора нет;
restore выключает автоматизации и повторно снимает тихую начальную точку истории.
