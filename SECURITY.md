# Безопасность

Не публикуйте токены, cookies, golden_key, SQLite, резервные копии или полные
HTTP-логи. Токен Telegram вводится только в локальном мастере настройки.
Сессионный ключ FunPay вводится в отдельном локальном диалоге. Доступны только
чтение профиля и списка чатов; сообщений покупателям и операций с лотами нет.
Никому не передавайте сессионные ключи для диагностики.

Перед публичным выпуском требуется настроить приватный канал сообщения об
уязвимостях (например, GitHub private vulnerability reporting). Сейчас репозиторий
не опубликован. Не раскрывайте действующие секреты в публичном Issue.

CredentialStore принудительно использует Windows backend keyring. SQLite и backup
не зашифрованы: безопасность зависит от доступа к Windows-профилю. Проверки
авторизации Telegram будут обязательным условием включения реальной отправки.
