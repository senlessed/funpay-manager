## Покрытие тестов

Миграция и повторный запуск; WAL/foreign_keys/busy_timeout; отказ от будущей схемы;
атомарный откат миграции при ошибке; конкурентные записи настроек; согласованная
копия и integrity_check; отклонение секретных ключей настроек; изоляция mock-чатов;
Qt offscreen запуск с временным профилем без ключей; отказ одной backend операции
при успешной другой; остановка до ready и повторная остановка; эксклюзивность и
освобождение QLockFile.

Окно дополнительно отрендерено offscreen и визуально просмотрено: русские подписи
и элементы помещаются, переписка не дублируется в GUI. Для offscreen-рендера был
явно загружен локальный Segoe UI — offscreen-плагин не подхватил шрифты автоматически.
Это не заменяет ручную проверку native Windows, DPI или трея.

## Исправления, обнаруженные проверками

Первый desktop smoke обнаружил повторный stop после закрытия event loop. Остановка
сделана идемпотентной, учитывает stop до ready и гонку закрытия loop; тест проходит.

Первый frozen smoke завершился ошибкой импорта QtCore. Проверка Analysis-00.toc
обнаружила ICU из стороннего Poppler в PATH окружения. После ограничения build PATH
Python-каталогом и Windows/System32 чужая ICU перестала попадать в сборку; frozen
smoke успешно прошёл. В CI установлен тот же механизм изоляции. Никакие системные
DLL вручную не заменялись и не скачивались.
