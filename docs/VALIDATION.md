обнаружила ICU из стороннего Poppler в PATH окружения. После ограничения build PATH
Python-каталогом и Windows/System32 чужая ICU перестала попадать в сборку; frozen
smoke успешно прошёл. В CI установлен тот же механизм изоляции. Никакие системные
DLL вручную не заменялись и не скачивались.

## Ещё не проверено

- Чистая Windows 10/11 без Python, Defender/SmartScreen, native tray и DPI.
- Первый мастер подключения — отсутствует; Credential Manager wrapper ещё не
  проверялся записью настоящих ключей.
- Telegram/FunPay network integration, права групп, Topics, реальная доставка,
  лоты/автоподнятие — отсутствуют; никаких реальных действий не выполнялось.
- Длительный soak, рост памяти, миграции будущих доменных таблиц и crash очереди.
- Публикация GitHub, GitHub Actions/Release, complete binary license notices.

Preview EXE — локальный артефакт этапа Windows-основы. Критерии публичного релиза
из ТЗ пока не выполнены. Коммитов и публикаций не делали.
